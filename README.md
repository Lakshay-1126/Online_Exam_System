# 📘 Online Exam System

A Java-based web application for managing online examinations, built using Servlets, JSP, JDBC, and MySQL with a clean layered architecture.

---

## 🚀 Features

- Add, Update, Delete Questions (CRUD Operations)
- Conduct Online Tests
- User Authentication (Login & Registration)
- Layered Architecture (Controller, DAO, DTO, Utility)
- JDBC-based Database Connectivity
- Simple UI using HTML & CSS

---

## 🛠️ Tech Stack

- Backend: Java, JDBC, Servlets, JSP
- Frontend: HTML, CSS
- Database: MySQL
- Server: Apache Tomcat
- IDE: Eclipse
